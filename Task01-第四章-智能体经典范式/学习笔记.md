# Task01: 第四章 智能体经典范式构建 - 学习笔记

## 1. 核心范式对比总览

| 范式名称 | 核心运作机制 | 核心优势 | 局限性与适用场景 |
| :--- | :--- | :--- | :--- |
| **ReAct** | `Thought -> Action -> Observation` 循环 | 边想边做，根据环境反馈动态纠偏 | 容易陷入局部细节死循环；适合工具调用频繁的即时交互 |
| **Plan-and-Solve** | 先出全局计划列表，再依次独立执行 | 谋定而后动，宏观把控长链路逻辑 | 计划缺乏执行过程中的动态弹性；适合多步骤计算与确定性流水线 |
| **Reflection** | 生成 -> 评估批判 -> 记忆反思 -> 优化重写 | 自我挑刺，通过多轮迭代逼近最优解 | Token 消耗倍增；适合代码生成、论文审阅与精细润色 |

## 2. 经典范式实战运行记录

### 2.1 Plan-and-Solve 运行记录
- **问题**: 水果店苹果买卖逻辑计算题
- **拆解步骤**: 5 步子计划
- **执行结果**: 成功得出最终答案 70

### 2.2 Reflection 运行记录
- **任务**: 编写 1 到 n 之间素数的 Python 函数
- **初稿**: 基础埃氏筛法 $O(n \log \log n)$
- **反思评判**: 发现重复标记瓶颈，建议升级线性欧拉筛
- **优化迭代**: 重构为 $O(n)$ 欧拉筛，第二轮反思判定“无需改进”终止
